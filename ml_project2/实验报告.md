# 实验报告

## 1. 实验目的

本实验使用 CUB-200-2011 数据集完成 200 类鸟类图像分类。相较于初始的单卷积层模型，本实验采用包含四个卷积层的卷积神经网络，并使用分层十折交叉验证评估模型的泛化能力。同时，通过数据增强、Batch Normalization、Dropout、权重衰减和 Label Smoothing 缓解过拟合。

## 2. 实验设置

- 数据集：CUB-200-2011，共 11,788 张图像、200 个类别。
- 交叉验证：StratifiedKFold，10 折，随机种子 42。
- 每折数据量：通常为 10,609 张训练图像和 1,179 张验证图像；第 9、10 折为 10,610/1,178。
- 输入图像：统一缩放为 `224×224`，三通道 RGB。
- 训练增强：随机水平翻转、归一化。
- 优化器：AdamW，初始学习率 `1e-3`，weight decay `1e-4`。
- 损失函数：带 `label_smoothing=0.1` 的交叉熵损失。
- 最大训练轮数初始设置为10；学习率调度器为 ReduceLROnPlateau。
- 评价指标：交叉熵损失和分类准确率。

## 3. 模型架构设计

模型输入尺寸为 `3×224×224`。卷积层使用 `3×3` 卷积核、步长 1、padding 1，因此卷积本身不改变空间尺寸；每个卷积块后使用 `2×2` 最大池化，将高和宽减半。最后使用自适应平均池化，使分类器不依赖于固定的空间尺寸。

| 层 | 结构 | 输入尺寸 | 输出尺寸 | 可训练参数 |
|---|---|---:|---:|---:|
| Input | RGB 图像 | `3×224×224` | `3×224×224` | 0 |
| Conv1 | Conv2d(3, 32, 3×3, padding=1) | `3×224×224` | `32×224×224` | 864 |
| BN1 | BatchNorm2d(32) | `32×224×224` | `32×224×224` | 64 |
| ReLU1 + Pool1 | ReLU；MaxPool2d(2) | `32×224×224` | `32×112×112` | 0 |
| Conv2 | Conv2d(32, 64, 3×3, padding=1) | `32×112×112` | `64×112×112` | 18,432 |
| BN2 | BatchNorm2d(64) | `64×112×112` | `64×112×112` | 128 |
| ReLU2 + Pool2 | ReLU；MaxPool2d(2) | `64×112×112` | `64×56×56` | 0 |
| Conv3 | Conv2d(64, 128, 3×3, padding=1) | `64×56×56` | `128×56×56` | 73,728 |
| BN3 | BatchNorm2d(128) | `128×56×56` | `128×56×56` | 256 |
| ReLU3 + Pool3 | ReLU；MaxPool2d(2) | `128×56×56` | `128×28×28` | 0 |
| Conv4 | Conv2d(128, 256, 3×3, padding=1) | `128×28×28` | `256×28×28` | 294,912 |
| BN4 | BatchNorm2d(256) | `256×28×28` | `256×28×28` | 512 |
| ReLU4 | ReLU | `256×28×28` | `256×28×28` | 0 |
| AdaptiveAvgPool | AdaptiveAvgPool2d(1,1) | `256×28×28` | `256×1×1` | 0 |
| Flatten | 展平 | `256×1×1` | `256` | 0 |
| Dropout | Dropout(0.4) | `256` | `256` | 0 |
| Classifier | Linear(256, 200) | `256` | `200` | 51,400 |

参数量计算如下：

- 卷积层：`864 + 18,432 + 73,728 + 294,912 = 387,936`。
- BatchNorm 层：`64 + 128 + 256 + 512 = 960`。这里统计的是可训练的缩放系数和偏置。
- 全连接层：`256×200 + 200 = 51,400`。
- **模型总参数量：`387,936 + 960 + 51,400 = 440,296`。**

该结构逐步扩大通道数（32→64→128→256），同时通过池化降低空间分辨率，能够提取从边缘、纹理到局部形状的层次化特征。AdaptiveAvgPool 将特征图压缩到一个空间位置，避免直接连接 `256×28×28` 导致全连接层参数过大。

从每一折的完整日志可以观察到：

但另一方面，即使增大至50epoch，前四折最佳验证准确率仍整体偏低，Fold 3最佳验证准确率仅为12.38%，且在第19个epoch即触发Early stopping。各折训练准确率与验证准确率差距总体不大，暂未表现出明显过拟合，更多仍表现为欠拟合或任务本身较难。后续仍需从模型容量、数据标签质量、类别不平衡、学习率与正则化设置、输入预处理等方面进一步排查。由于目前仅获得前四折50epoch日志，尚不能给出完整的50epoch十折交叉验证均值与标准差，因此不能与10epoch十折结果进行严格统计比较，但趋势上已说明增加训练轮数是必要的。


## 6. 过拟合分析与改进措施

本实验没有出现典型的严重过拟合。典型过拟合应表现为训练 loss 持续下降、训练准确率持续上升，而验证 loss 持续上升、验证准确率持续下降。本次实验中训练和验证指标总体同步改善，最终训练准确率与验证准确率的差距通常只有几个百分点，部分 fold 的验证准确率甚至略高于训练准确率。

验证准确率高于训练准确率并不矛盾，主要原因是训练阶段启用了 Dropout 和随机水平翻转，且训练损失使用了 Label Smoothing；验证阶段关闭 Dropout、没有随机增强，因此验证过程相对确定。此外，训练集指标是在参数更新过程中的 batch 上累计，验证指标是在完整 epoch 结束后计算，二者并非完全同一条件下的测量。

代码中已采取以下抑制过拟合措施：

- BatchNorm：稳定不同 batch 的特征分布，加快训练收敛。
- Dropout(0.4)：降低分类器对单一特征的依赖。
- AdamW weight decay：约束模型参数规模。
- 随机水平翻转：增加训练样本的外观变化。
- Label Smoothing：降低模型过度自信。
- ReduceLROnPlateau 和 Early Stopping：验证指标不再改善时降低学习率或停止训练。

## 7. 结果讨论与改进方向

虽然模型满足了“至少三层卷积”和“十折交叉验证”的作业要求，但 8.71% 的平均 Top-1 准确率仍然较低。CUB-200-2011 是细粒度分类数据集，不同鸟类之间的差异主要集中在头部、翅膀、喙等局部区域，仅使用从零开始训练的小型 CNN 难以获得足够强的判别特征。后续可以考虑：

1. 使用 ImageNet 预训练的 ResNet、EfficientNet 或 ConvNeXt，并对最后分类层进行微调。
2. 使用更适合细粒度识别的随机裁剪、颜色扰动和目标区域裁剪。
3. 增加训练 epoch，并根据验证集曲线调整学习率和 patience。
4. 引入类别均衡采样、MixUp 或 CutMix 等增强方法。
5. 报告 Top-5 准确率和混淆矩阵，以更全面地评价细粒度分类效果。

## 8. 结论

本实验构建了一个总参数量为 440,296 的四卷积层 CNN，并在 CUB-200-2011 上完成了十折分层交叉验证。实验得到的平均最佳验证准确率为 **8.71% ± 0.51%**。训练和验证 loss 整体下降、准确率整体上升，说明模型能够学习数据中的类别信息；同时没有观察到严重的训练集过拟合。模型性能的主要瓶颈在于 CUB 数据集的细粒度特征和从零训练的小型网络容量，后续使用预训练模型和更强的局部区域增强预计能够显著提升分类准确率。
