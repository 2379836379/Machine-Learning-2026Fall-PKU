# 实验报告

## 1. 实验目的

本实验使用 CUB-200-2011 数据集完成 200 类鸟类图像分类。相较于初始的单卷积层模型，本实验采用包含四个卷积层的卷积神经网络，并使用分层十折交叉验证评估模型的泛化能力。同时，通过数据增强、Batch Normalization、Dropout、权重衰减和 Label Smoothing 缓解过拟合。

## 2. 实验设置

- 数据集：CUB-200-2011，共 11,788 张图像、200 个类别。
- 交叉验证：StratifiedKFold，10 折，随机种子 42。
- 每折数据量：通常为 10,609 张训练图像和 1,179 张验证图像；第 9、10 折为 10,610/1,178。
- 输入图像：统一缩放为 224×224，三通道 RGB。
- 训练增强：随机水平翻转、归一化。
- 优化器：AdamW，初始学习率 1e-3，weight decay 1e-4。
- 损失函数：带 label_smoothing=0.1 的交叉熵损失。
- 最大训练轮数初始设置为10；学习率调度器为 ReduceLROnPlateau。

## 3. 模型架构设计

模型输入尺寸为 3×224×224。卷积层使用 3×3 卷积核、步长 1、padding 1。每个卷积块后使用 2×2 池化，最后使用自适应平均池化，使分类器不依赖于固定的空间尺寸。

| 层 | 结构 | 输入尺寸 | 输出尺寸 | 可训练参数 |
|:---:|:---:|:---:|:---:|:---:|
| Input | RGB 图像 | 3×224×224 | 3×224×224 | 0 |
| Conv1 | Conv2d(3, 32, 3×3, padding=1) | 3×224×224 | 32×224×224 | 864 |
| BN1 | BatchNorm2d(32) | 32×224×224 | 32×224×224 | 64 |
| ReLU1 + Pool1 | ReLU；MaxPool2d(2) | 32×224×224 | 32×112×112 | 0 |
| Conv2 | Conv2d(32, 64, 3×3, padding=1) | 32×112×112 | 64×112×112 | 18,432 |
| BN2 | BatchNorm2d(64) | 64×112×112 | 64×112×112 | 128 |
| ReLU2 + Pool2 | ReLU；MaxPool2d(2) | 64×112×112 | 64×56×56 | 0 |
| Conv3 | Conv2d(64, 128, 3×3, padding=1) | 64×56×56 | 128×56×56 | 73,728 |
| BN3 | BatchNorm2d(128) | 128×56×56 | 128×56×56 | 256 |
| ReLU3 + Pool3 | ReLU；MaxPool2d(2) | 128×56×56 | 128×28×28 | 0 |
| Conv4 | Conv2d(128, 256, 3×3, padding=1) | 128×28×28 | 256×28×28 | 294,912 |
| BN4 | BatchNorm2d(256) | 256×28×28 | 256×28×28 | 512 |
| ReLU4 | ReLU | 256×28×28 | 256×28×28 | 0 |
| AdaptiveAvgPool | AdaptiveAvgPool2d(1,1) | 256×28×28 | 256×1×1 | 0 |
| Flatten | 展平 | 256×1×1 | 256 | 0 |
| Dropout | Dropout(0.4) | 256 | 256 | 0 |
| Classifier | Linear(256, 200) | 256 | 200 | 51,400 |

参数量计算如下：

- 卷积层：864 + 18,432 + 73,728 + 294,912 = 387,936。
- BatchNorm 层：64 + 128 + 256 + 512 = 960。
- 全连接层：256×200 + 200 = 51,400。
- 总参数量：387,936 + 960 + 51,400 = 440,296。

## 6. 过拟合分析
初始模型出现严重过拟合，baseline 训练结果如下：

| Epoch | Train Loss | Train Acc | Val Loss | Val Acc |
|:---:|:---:|:---:|:---:|:---:|
| 1/10 | 5.3691 | 0.0482（4.82%） | 4.6435 | 0.0645（6.45%） |
| 2/10 | 3.2910 | 0.2916（29.16%） | 4.7231 | 0.0848（8.48%） |
| 3/10 | 1.3916 | 0.7029（70.29%） | 5.6962 | 0.0780（7.80%） |
| 4/10 | 0.3849 | 0.9300（93.00%） | 6.7137 | 0.0738（7.38%） |
| 5/10 | 0.1458 | 0.9763（97.63%） | 7.2547 | 0.0628（6.28%） |
| 6/10 | 0.1131 | 0.9811（98.11%） | 7.6480 | 0.0636（6.36%） |
| 7/10 | 0.0931 | 0.9849（98.49%） | 7.9066 | 0.0704（7.04%） |
| 8/10 | 0.0673 | 0.9879（98.79%） | 7.6159 | 0.0746（7.46%） |
| 9/10 | 0.0834 | 0.9835（98.35%） | 7.8968 | 0.0687（6.87%） |
| 10/10 | 0.0628 | 0.9879（98.79%） | 8.3759 | 0.0653（6.53%） |

第 1 轮训练准确率为 4.82%，第 5 轮升到 97.63%，第 10 轮达到 98.79%。验证准确率却始终很低，这说明模型很快记住了训练图像，却没有学到能泛化到新图像的特征。主要原因是初始模型虽然只有一个卷积层，共计大约有 251 万个参数，其中绝大部分集中在全连接层。与此同时，训练方案没有 Dropout、权重衰减或数据增强，CUB-200 又是有 200 类的细粒度分类任务，只靠一层卷积很难提取足够有区分度的鸟类局部特征。

当前模型没有出现典型的过拟合，主要原因是代码中已采取以下抑制过拟合措施：
- BatchNorm：稳定不同 batch 的特征分布，加快训练收敛。
- Dropout(0.4)：降低分类器对单一特征的依赖。
- AdamW weight decay：约束模型参数规模。
- 随机水平翻转：增加训练样本的外观变化。
- Label Smoothing：降低模型过度自信。
- ReduceLROnPlateau 和 Early Stopping：验证指标不再改善时降低学习率或停止训练。

## 7. 结果讨论

模型平均准确率较低，CUB-200-2011 是细粒度分类数据集，仅使用从零开始训练的小型 CNN 难以获得足够强的判别特征。后续可以考虑：
1. 使用预训练的模型，对最后分类层进行微调。
2. 修改模型结构，增加可训练参数。
3. 使用更适合细粒度识别的随机裁剪、颜色扰动和目标区域裁剪。
